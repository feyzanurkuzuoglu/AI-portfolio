# PyTorch Zero to Mastery – Course Exercises

This repository contains my code-along notebooks, exercises, and experiments completed while studying the **Learn PyTorch for Deep Learning: Zero to Mastery** course by Daniel Bourke.

Course materials:
- https://www.learnpytorch.io/
- https://github.com/mrdbourke/pytorch-deep-learning

The course follows a hands-on, code-first approach to learning PyTorch and deep learning. These notebooks were created while following the course videos and online book, reproducing examples, completing exercises, and experimenting with the concepts introduced in each section.

## Topics Covered

### 00 – PyTorch Fundamentals
- tensors and tensor operations
- random tensors
- tensor shapes
- indexing
- NumPy and PyTorch interoperability
- reproducibility
- device-agnostic code

### 01 – PyTorch Workflow Fundamentals
- preparing data
- building PyTorch models
- loss functions and optimizers
- training and testing loops
- saving and loading models

### 02 – Neural Network Classification
- binary classification
- multiclass classification
- nonlinear activation functions
- evaluation metrics
- decision boundaries

### 03 – Computer Vision
- torchvision datasets
- DataLoaders
- convolutional neural networks
- FashionMNIST
- training and evaluating CNN models

### 04 – Custom Datasets
- loading image datasets
- image transformations
- custom Dataset classes
- DataLoaders for custom image data
- data augmentation

### 05 – Going Modular
- separating PyTorch code into Python modules
- data setup
- model definitions
- training functions
- reusable training pipelines

### 06 – Transfer Learning
- pretrained models
- torchvision model weights
- feature extraction
- modifying classifier layers
- training pretrained models on custom datasets

## Notes

The code in this directory is primarily educational coursework rather than original standalone projects.

Many examples closely follow the original course material while I coded along with the lessons. I also completed exercises and made small modifications and experiments where appropriate.

For my independent PyTorch experiments and projects, see the other directories in this repository.
